== Approach

A file of its own in `pkg/x11`, `extensions.go`: the names of the six
extensions; `setupExtensions`, which asks for them on a connection of its
own, closes it, drains its events to the end of its reader and writes the
tables; `NewConn`, which runs the setup once (`sync.OnceValues`), then
connects as `xgb.NewConn` does and copies the major opcodes into the new
connection's `Extensions` under its `ExtLock`; `CheckExtension`, which
reports an extension absent from a connection's `Extensions`. The file
imports the six packages of xgb for the `init` that fills their
`NewExtEventFuncs` and `NewExtErrorFuncs`.

Every `xgb.NewConn` of the program becomes `x11.NewConn`, and every `Init`
a `CheckExtension` of the same extension, before the version query that
follows it as now. `pkg/composite` imports `pkg/x11` for it; `pkg/x11`
imports neither `pkg/composite` nor `pkg/snapshot`.

At the start, with the change: `x11.Connect` makes the first connection,
so the setup runs inside it, before the main connection and every other
exists; `snapshot.New`, the capturer of 1.0.0 and `x11.NewModel` find the
extensions set up. `cmd/qws/root.go` does not change.
