== Where the time goes

35 client windows; five runs.

[cols="3,2",options="header"]
|===
| Step, all windows | ms
| `_NET_CLIENT_LIST` | 0.1–3.3
| the name, `_NET_WM_NAME` or `WM_NAME` | 2.4–7.4
| the state, for skip-taskbar | 2.0–5.1
| the desktop and the names of the desktops | 3.9–4.3
| the icon, `_NET_WM_ICON` read whole and decoded | 46.5–72.7
| the hints and the state, for urgency | 3.5–18.3
| *the steps* | *69–97*
| *`GetWindowListFiltered`* | *152–182*
|===

The difference, some 75 ms, is the one step the probe does not repeat: for
the 6 windows without `_NET_WM_ICON`, `findIconByClass` reads the desktop
files of `/usr/share/applications` and the icon directories, every
activation, about 12 ms a window.

The icons of the 35 windows weigh 28.3 MB: `_NET_WM_ICON` holds every size
a window offers, up to 512×512; the switcher shows one, nearest to 48
pixels.

The rest are round trips: some 175 requests, each waiting for its reply,
0.1–0.5 ms each on E1.

== The model

The same probe, the branch, 2026-10-01, 35 windows, VNC not connected; 100
lists 50 ms apart:

[cols="3,2",options="header"]
|===
| | p50 / p95 / max, ms
| the list from the model, `Model.List` | 0.12 / 3.20 / 16.40
| a bare round trip, `GetInputFocus`, on a connection of its own | 0.16 / 3.80 / 5.13
| the queries, `GetWindowListFiltered` — the icons by class now kept | 68.69 / 79.37 / 89.37
|===

The tail of the list is the tail of its one round trip. The model reads all
windows in 23–30 ms at the start. The queries, the path without the model,
went from 152–182 ms to 68–89 ms by the icons by class alone.

VNC, when connected, holds the X server some 18 ms several times a second
(`x0vncserver` fetching the whole screen on damage, found by another
session of the author, 2026-10-01); a round trip, the list's too, can wait
that long then.
