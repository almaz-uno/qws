== Approach

A file of its own in `pkg/x11`, `xids.go`: `nextXIDs`, the range function,
which asks `xcmisc.GetXIDRange` and returns the range of its reply through
`xidRange`, which turns the answer of none, start 0 and count 1, into the
error `errNoXIDs`.

`pkg/x11/extensions.go`: XC-MISC joins `extensionNames`, and its package
the blank imports, so that the setup of 021 asks for it with the others and
every connection gets its opcode; `NewConn` sets `nextXIDs` with
`SetIDRangeFunc` on the connection it made when the opcodes of the setup
have XC-MISC; `setupExtensions`, run once per process, logs the warning
when they have not.

Nothing else changes: `x11.Connect`, `x11.NewModel` and `snapshot.New`
connect through `NewConn` already, and `cmd/qws/root.go` does not change.
