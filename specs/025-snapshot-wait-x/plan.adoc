== Approach

`pkg/glx` gets `(*Offscreen).WaitX`, `glXWaitX` through a C function
`offWaitX`, as 020's branch has them. `captureGPU` calls it right before
`BindPixmap` of a pixmap just named and right before `Rebind`; the paths
that return before binding — a window taken from its frame, a pixmap the GPU
refused — do not call it. `TestGPUThumbnail` calls it before its
`BindPixmap` and before its `Rebind`.
